ОЗВУЧКА ИГРЫ «ХОУМЛЕНДЕР: ЯРОСТЬ»

scripts/   — тексты реплик, по одному файлу на персонажа (с подсказками, как играть).
audio/     — сюда кладутся записи: <id>.mp3, например hl_001.mp3.
lines.json — список всех реплик с их id (генерируется скриптом).

Как добавить записи:
1. Записать каждую реплику отдельным файлом и назвать по её id (hl_001.mp3, but_007.mp3 …).
2. Положить файлы в audio/ (wav/ogg можно — переконвертируем в mp3).
3. Запустить: python3 voice/build_lines.py  — игра сама начнёт проигрывать записи.
Номера реплик постоянные: если тексты поменяются, уже записанные файлы не съедут.
